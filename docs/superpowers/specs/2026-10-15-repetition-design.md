# Joseki Dojo — повторение: уровень игрока, карточки и FSRS

- Дата: 2026-10-15
- Статус: согласовано в обсуждении
- Опирается на: [ядро](2026-10-06-core-free-mode-design.md) (разбор, категории ходов, ненаказанные ошибки), [стартовые позиции](2026-10-13-start-positions-design.md) (дерево «Из списка»), [языки](2026-10-14-languages-design.md) (словари, термины)
- Часть 4 общего плана (тренажёр): первая и вторая итерации.

## 1. Цель

Тренажёр запоминает, что игрок уже разбирал, и возвращает это к повторению по расписанию: дзёсеки из дерева нужно снова доиграть, а позиции, где игрок ошибся или не наказал ошибку бота, становятся задачами «найдите хороший ход». Пороги «неточность / ошибка / зевок» перестают быть общими для всех и зависят от уровня игрока; сами пороги выводятся из того, как на самом деле ходят игроки каждого ранга.

## 2. Объём

**Входит:**
- настройка «Ваш уровень» и пороги категорий по уровню (раздел 3);
- калибровка порогов по человеческой сети KataGo — скрипт, который владелец запускает отдельно на машине с видеокартой (раздел 3.3);
- карточки двух видов, их создание после разбора и расписание по FSRS (раздел 4);
- вкладка «Повторение»: сводка, прогноз, список карточек, очередь (раздел 5);
- задача на один ход с оценкой хода KataGo на лету (раздел 5.4);
- прогресс в дереве «Из списка» (раздел 6);
- все новые надписи на шести языках интерфейса.

**Не входит:**
- карточки из позиций других игроков, импорт партий, синхронизация между устройствами;
- подбор параметров FSRS под игрока (оптимизатор): используются стандартные параметры;
- дневные лимиты и «новые карточки в день»: карточки появляются только из собственных тренировок;
- объяснения ошибок словами (часть 2 общего плана).

**Две итерации, у каждой свой PR** (раздел 10): первая — уровень, калибровка, хранилище карточек, карточки-позиции, вкладка и прогресс в дереве; вторая — карточки-задачи и экран задачи.

## 3. Уровень игрока и пороги

### 3.1 Настройка
- В настройках — «Ваш уровень»: 20 кю … 1 кю, 1 дан … 9 дан, «профи» (30 значений; шкала рангов бота плюс «профи»). Хранится в конфиге как `player.level` (`20k` … `1k`, `1d` … `9d`, `pro`); по умолчанию `7k` — как сила бота по умолчанию.
- От уровня зависят пороги категорий хода (`inaccuracy`, `mistake`, `blunder`) и порог наказания (`punished`). Ими пользуются разбор (категории ходов, ненаказанные ошибки бота), создание карточек (4.2) и оценка повторения (4.4).
- Смена уровня действует сразу: разбор при следующем показе считает категории по новым порогам. Уже созданные карточки не пересоздаются и не удаляются.

### 3.2 Пороги по уровню
- Таблица порогов — файл `packages/server/bases/thresholds.json`, его пишет калибровка (3.3): для каждого из 30 уровней — `inaccuracy`, `mistake`, `blunder`.
- Порог наказания: ответ на ошибку бота считается наказанием, если сам он не хуже неточности вашего уровня, то есть `punished = inaccuracy` уровня.
- Нет файла или он повреждён — для всех уровней действуют пороги из конфига (`thresholds`, по умолчанию 0,5 / 2 / 5, наказание — 1), в журнал сервера одна строка с причиной. Так приложение работает и до первой калибровки.
- Проверка таблицы при чтении: для каждого уровня `0 < inaccuracy < mistake < blunder`; по мере роста уровня пороги не растут. Нарушение — файл не принимается целиком (действуют пороги конфига, строка в журнале).

### 3.3 Калибровка
Порог — не произвольное число, а свойство того, как ходят игроки этого уровня в дзёсеки.

- **Позиции:** обычные стартовые позиции из `starts.jdb` (без стартов после хода похуже); по умолчанию случайная выборка из 400 позиций с фиксированным зерном, чтобы прогон повторялся.
- **Как ходит уровень:** для каждой позиции и каждого уровня человеческая сеть даёт распределение ходов (`humanSLProfile`: `rank_20k` … `rank_9d`, для «профи» — `proyear_2023`, проверяется перед прогоном; один визит, `includePolicy`).
- **Потери:** для каждой позиции оцениваются ходы, которые вместе покрывают не меньше 98 % вероятности у каждого уровня (объединение по уровням). Потеря хода считается так же, как в разборе (ядро, 9.2): разница `scoreLead` корня позиции и позиции после хода, с точки зрения ходившего; анализ основной сетью, по умолчанию 2000 визитов на позицию. Непокрытый остаток вероятности (до 2 %) получает потерю худшего оценённого хода этой позиции — так верхние доли не занижаются.
- **Распределение уровня:** все позиции с равным весом, ходы внутри позиции — с весом вероятности хода у этого уровня.
- **Пороги:** потеря, которую ход этого уровня превышает в 25 % случаев, — `inaccuracy`; в 10 % — `mistake`; в 3 % — `blunder`. То есть «ошибка» — ход, хуже которого игрок вашего уровня ходит лишь в одном случае из десяти.
- **Сглаживание:** пороги округляются до 0,05 и делаются невозрастающими по уровню (если сильный уровень вышел с порогом выше слабого, берётся меньшее); минимальный порог — 0,05. Каждое такое исправление печатается в отчёте.
- **Запуск:** `npm run thresholds:gpu -- [--positions N] [--visits N] [--seed N] [--restart]` по образцу проверки ловушек: отказывается работать на `main`, на detached HEAD и с незакоммиченным `thresholds.json`; проверяет, что KataGo отвечает с человеческой сетью; печатает таблицу и отчёт (сколько позиций, ходов, визитов, время, сглаживания); пишет `thresholds.json` (с полями метода: число позиций, визиты, зерно, доли 25/10/3, версия KataGo и имена сетей) и коммит с одним этим файлом и отчётом в описании. Отправляет коммит владелец. Прерванный прогон продолжается той же командой с последней сохранённой позиции ([продолжение после обрыва](2026-10-23-thresholds-resume-design.md)).
- Владелец запускает калибровку отдельным шагом на мощной машине и смотрит таблицу до отправки.

## 4. Карточки

### 4.1 Виды
1. **Позиция** — стартовая позиция дерева «Из списка». Задание: доиграть дзёсеки с этой позиции против бота. Ключ — идентификатор старта.
2. **Задача** — «найдите хороший ход» в позиции из вашей тренировки. Источник — только подпись:
   - **ваша ошибка** — позиция перед вашим ходом в углу, категория которого «ошибка» или «зевок» по порогам вашего уровня;
   - **ненаказанная ошибка бота** — позиция после ошибки бота, на которую вы ответили хуже порога наказания.
   Ключ — позиция: камни переносятся так, чтобы угол тренировки стал правым верхним, и приводятся к каноническому виду по диагонали (как пути в JDB), плюс цвет того, кто ходит. Та же позиция из другой партии или из другого угла — та же карточка.

### 4.2 Создание
- Карточки создаются на сервере, когда разбор завершённой тренировки посчитан и сохранён (в любом режиме), один раз на тренировку.
- **Позиция:** тренировка начиналась со старта, который есть в списке (режимы «Из списка» и «Случайно»). Нет карточки — создаётся; есть — это её очередное повторение. Карточка хранит идентификатор старта, цвет игрока и силу бота той тренировки, которая её создала.
- **Задача (итерация 2):** каждый ваш ход в зоне угла с категорией «ошибка» или «зевок» и каждая ненаказанная ошибка бота. Ходы до начальной позиции (стартовые ходы) не считаются. Нет карточки с таким ключом — создаётся; есть — это её повторение с оценкой «Снова».
- Само событие — первое повторение карточки: у позиции — с оценкой тренировки (4.4), у задачи — «Снова».
- Задача хранит всё нужное для показа без исходной партии: ходы до позиции в углу исходной тренировки, цвет игрока, источник, ваш ход и его потерю, анализ позиции из разбора (`scoreLead` корня, кандидаты с вариантами) и число визитов. Удаление старых тренировок карточки не ломает.
- Карточку можно удалить во вкладке; удалённая не возвращается, если та же позиция снова встретится (ключ запоминается как удалённый).

### 4.3 Расписание
- FSRS через библиотеку `ts-fsrs` (MIT, точная версия в `package.json`): стандартные параметры, целевая вероятность вспомнить 0,9, короткие шаги обучения включены — карточка с «Снова» возвращается через минуты в той же сессии повторения.
- Состояние карточки (стабильность, сложность, этап, срок) хранится целиком; каждое повторение пишется в журнал с оценкой, автоматической оценкой и состоянием до повторения.
- Сроки и «сегодня» считаются по местному времени компьютера; день начинается в 4:00 (как в Anki), чтобы поздний вечер не делился пополам.

### 4.4 Оценка
- Оценку ставит приложение по KataGo; четыре кнопки («Снова», «Трудно», «Хорошо», «Легко») показывают её выбранной и позволяют поменять, пока экран открыт. Новая оценка заменяет автоматическую: расписание пересчитывается от состояния до этого повторения.
- **Задача:** лучший ход KataGo (первый кандидат) — «Легко»; «точно» — «Хорошо»; «неточность» — «Трудно»; «ошибка» и «зевок» — «Снова».
- **Позиция:** худшая категория ваших ходов в зоне угла после стартовой позиции; ненаказанная ошибка бота считается ошибкой, если ошибочный ход бота был в зоне угла (где бы вы ни ответили). «Точно» — «Хорошо», «неточность» — «Трудно», «ошибка», «зевок» или ненаказанная ошибка — «Снова». «Легко» — только кнопкой. Тренировка, в которой вы не сделали ни одного хода в зоне угла, повторением не считается.

### 4.5 Хранение
Миграция 004:
- `cards`: идентификатор, вид (`position` | `move`), ключ (уникальный), данные карточки (JSON: старт или позиция задачи, 4.2), состояние FSRS (JSON), срок, время создания, признак удаления.
- `card_reviews`: идентификатор, карточка, время, оценка, автоматическая оценка, состояние FSRS до повторения (JSON), тренировка-источник (для позиции и задачи, созданной из тренировки) или null (ответ на экране задачи).

## 5. Повторение

### 5.1 Вкладка «Повторение»
- Третья вкладка в шапке рядом с «Игра» и «Настройки», со счётчиком карточек, которые пора повторить (без счётчика, когда их нет).
- **Сводка:** пора повторить сейчас — всего и по видам; прогноз на 7 дней (сколько станет пора по дням); всего карточек и сколько из них уже на этапе повторения (изучены).
- **«Начать повторение»** — запускает очередь (5.2); без карточек к повторению кнопка недоступна, рядом — когда ближайшая.
- **Список карточек:** вид, маленькая доска угла, название (у позиции — её название из списка; у задачи — источник, группа угла и номер хода исходной тренировки), когда повторять, последняя оценка, «Удалить» с подтверждением. Фильтр по виду; порядок — по сроку.

### 5.2 Очередь
- Карточки, которым пора, по сроку; задача открывает экран задачи (5.4), позиция — тренировку (5.3). Если сейчас ничего не пора, очередь берёт карточку на этапе обучения, которой пора в ближайшие 20 минут (как в Anki), — так карточка с «Снова» возвращается в той же сессии.
- Карточка-позиция, старта которой больше нет в списке, в очередь и счётчики не попадает; в списке карточек она показана с пометкой, чтобы её можно было удалить.
- После каждой карточки — «Дальше» (следующая карточка, включая вернувшиеся по коротким шагам) и «Закончить» (назад во вкладку). Когда карточек к повторению не осталось — «На сегодня всё» и возврат во вкладку.

### 5.3 Карточка-позиция
- Тренировка как в «Из списка»: тот же старт, угол — случайный, цвет и сила бота — как в тренировке, которая создала карточку.
- После тренировки — обычный разбор; над ним панель повторения: автоматическая оценка с объяснением одной строкой («худший ход: ошибка, −2,4») и четыре кнопки (4.4). Кнопки «Дальше» и «Закончить» очереди — в той же панели.
- Тренировка той же позиции вне очереди (из дерева или «Случайно») тоже засчитывается как повторение, с той же панелью в разборе.

### 5.4 Задача на один ход (итерация 2)
- Доска — вся, как в исходной тренировке (тот же угол и цвета), последний ход отмечен. Заголовок: «Найдите хороший ход» и подпись источника («ваша ошибка» / «бот ошибся — накажите»).
- Один щелчок по доске — ответ. Потеря хода: если ход есть среди сохранённых кандидатов, она берётся оттуда; иначе KataGo анализирует позицию после хода с визитами разбора, и потеря считается как в разборе. На время оценки — «KataGo считает…».
- Затем: категория вашего хода и потеря, лучший ход KataGo с веткой (как в разборе — шагами), ваш исходный ход из тренировки (для своей ошибки), автоматическая оценка и четыре кнопки, «Дальше» и «Закончить». На панели — «Повторение задачи» и только автоматическая оценка: категория и потеря уже названы выше.
- Ответ можно дать в любой точке доски, не только в зоне угла: лучшим ходом может быть и ход в другом месте.
- KataGo недоступен — задача показывает «Оценка недоступна», повторение не засчитывается и ничего не записывается; «Дальше» и «Закончить» остаются. «Дальше» ведёт к следующей карточке очереди — пока KataGo недоступен, это та же задача: она остаётся самой просроченной (очередь без KataGo всё равно не движется — позиции играются с ботом).
- Если запрос оценки не удался по другой причине (например, задачу удалили в другом окне), кнопки очереди тоже показываются.
- Переход в другой раздел с открытой задачей завершает очередь; разбор позиции из очереди сохраняет «Дальше» и «Закончить», как раньше.

## 6. Прогресс в дереве «Из списка»
- У позиции в оглавлении и на карточке продолжения — отметка: «изучается» (карточка на этапе обучения), «изучена» (на этапе повторения, срок не наступил) или «пора повторить». Без карточки — без отметки.
- У группы и ветки — «изучено N из M» (позиции внутри на этапе повторения из всех позиций внутри) и, если есть, сколько пора повторить.
- Рядом с полным названием выбранной позиции — когда повторять.

## 7. API
- `GET /api/cards/summary` — сводка вкладки (5.1) и счётчик для шапки.
- `GET /api/cards?kind=` — список карточек (5.1); `DELETE /api/cards/:id` — удаление.
- `GET /api/cards/due` — следующая карточка к повторению или пусто.
- `GET /api/cards/starts` — состояние карточек-позиций по идентификаторам стартов (для дерева, раздел 6).
- `PUT /api/cards/reviews/:id` — замена оценки повторения (4.4).
- Итерация 2: `POST /api/cards/:id/answer` с ходом — оценка ответа задачи (5.4), ответ: категория, потеря, лучший ли это ход KataGo, первый кандидат KataGo с веткой, повторение (автоматическая и текущая оценка, идентификатор повторения, срок). Ошибки: 400 — нельзя ходить в эту точку, 404 — задачи нет, 409 — это не задача, 503 — KataGo недоступен.
- Разбор (`ReviewData`) получает поле с повторением этой тренировки: карточка, автоматическая и текущая оценка, идентификатор повторения.

## 8. Языки
Все новые надписи — в словарях шести языков интерфейса; термины (уровни, категории, «повторение», оценки FSRS) — по глоссарию терминов; новые термины добавляются в глоссарий.

## 9. Проверка
- **Пороги:** чтение таблицы, отказ при нарушении порядка или монотонности, запасные пороги конфига; разбор считает категории по уровню.
- **Калибровка:** выбор ходов по покрытию 98 %, взвешенные доли, сглаживание и округление — на маленьком наборе с поддельным движком; разбор параметров запуска; отказ на `main` и с незакоммиченным файлом.
- **Карточки:** создание из разбора (позиция; во второй итерации — задачи), ключ задачи одинаков для той же позиции в другом углу и в отражении, повтор существующей карточки, удалённая не возвращается; расписание и замена оценки (пересчёт от состояния до повторения); правила автоматической оценки.
- **API:** сводка, список, удаление, следующая карточка, состояние стартов, замена оценки; ответ задачи на поддельном движке (итерация 2).
- **Экран:** вкладка со счётчиком, сводкой и списком; отметки в дереве.
- **Сквозные тесты:** тренировка позиции из дерева создаёт карточку, она видна во вкладке и в дереве; очередь проводит через позицию и (итерация 2) задачу, оценка меняется кнопкой.

## 10. Итерации
