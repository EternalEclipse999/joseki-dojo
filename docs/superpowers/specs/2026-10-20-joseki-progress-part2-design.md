## 1. Что делает часть 2

1. **Запоминает:** после каждой тренировки проходит её ходы по графу и записывает повторения карточкам хода (узлы, где ходил игрок) и карточкам остатка (где розыгрыш покинул граф).
2. **Считает:** процент каждой позиции списка, ветки, группы и всего дерева для цвета игрока и его уровня.
3. **Показывает:** сводку над деревом «Из списка» и проценты в его строках.
4. **Пересчитывает при смене уровня:** оценки всех повторений выводятся заново из сохранённых потерь, состояния FSRS проигрываются с начала — и у новых карточек, и у нынешних карточек позиций и задач.

Без файла весов (калибровка `tree:gpu` не проведена) часть 2 ничего не показывает и не мешает. Карточки при этом всё равно записываются: позже, когда веса появятся, прогресс сразу будет виден за всю историю.

## 2. Карточки графа

### 2.1 Виды и ключи

- **Карточка хода** — узел графа, где ход цвета игрока. Ключ — ключ позиции узла (в нём уже есть сторона хода), поэтому одна карточка на узел.
- **Карточка остатка** — узел и цвет игрока: в одном узле розыгрыш может покинуть граф и у чёрного игрока, и у белого. Ключ — ключ позиции и цвет игрока.
- **Хранится ключ позиции, а не номер узла:** номера меняются при пересборке графа. Карточка узла, которого после пересборки нет, хранится, но в процент не входит.
- **В очередь «Повторение» не попадают** и с карточками позиций и задач не смешиваются (решение владельца 5).

### 2.2 Хранение

Новая миграция с двумя таблицами:
- `graph_cards`: ключ, вид (ход / остаток), цвет игрока, состояние FSRS, срок, дата создания;
- `graph_reviews`: карточка, время, тренировка, ручная оценка (пусто, пока игрок её не менял), автооценка, **сырые данные** для пересчёта (2.4).

Плюс таблица встреченных позиций вне графа (ключ позиции, первая встреча) для правила 3.3.

### 2.3 Какие тренировки засчитываются

- Тренировки в любом режиме: свободная, из списка, случайная, из очереди, с ловушкой. Граф начинается с пустого угла, стартовые ходы проходят по нему так же, как ходы партии.
- **Не засчитываются** «переиграть с хода N» и продолжения после разбора: в них игрок только что видел вариант. Это то же правило, что у карточек позиций.
- Учитываются только ходы в угловой зоне тренировки. Ход вне зоны — тенуки.

### 2.4 Сырые данные повторения

- **Карточка хода:** потеря хода игрока и был ли он лучшим ходом KataGo.
- **Карточка остатка:**
  - для каждого хода игрока в зоне после выхода из графа — потеря, ключ позиции перед ходом и встречалась ли она раньше;
  - для каждой ошибки соперника в зоне после выхода — потеря соперника и потеря ответа игрока.

## 3. Запись тренировки

### 3.1 Проход по графу

После разбора тренировки ходы (стартовые и партии) проходятся с пустого угла:
- текущий узел — `nodeOfTraining` для позиции перед ходом, ориентация пересчитывается на каждом шаге;
- ход ищется среди рёбер узла через `toNodeMove`.

Розыгрыш **выходит из графа** в узле, когда ход:
- не найден среди рёбер;
- найден, но ребро без продолжения (`to` пусто);
- идёт по ребру назад — ребру, разрывающему цикл графа (4.2). Позиция, уже пройденная в этой тренировке, при таком правиле повториться не может; проверка остаётся как страховка.

После выхода проход прекращается.

### 3.2 Повторения карточек хода

В каждом узле пути, где ходил игрок, — повторение карточки хода этого узла, оценка по ходу:

| Ход | Оценка |
|---|---|
| лучший ход KataGo | «Легко» |
| точный | «Хорошо» |
| неточность | «Трудно» |
| ошибка, грубая ошибка | «Снова» |

Узлы стартовых ходов (до первого хода игрока в тренировке) повторений не получают: эти ходы игрок не выбирал.

### 3.3 Повторение карточки остатка

Если розыгрыш вышел из графа, карточка остатка узла выхода (для цвета игрока) получает одно повторение. Оценка — по худшему из ходов игрока в зоне после выхода и ненаказанных ошибок соперника в зоне после выхода, как у карточек позиций:

| Худшее | Оценка |
|---|---|
| всё точно | «Хорошо» |
| неточность | «Трудно» |
| ошибка, грубая ошибка, ненаказанная ошибка соперника | «Снова» |

**Исключение:** если все ошибки (не неточности) сделаны в позициях, которые игрок встретил впервые, оценка «Трудно», а не «Снова» (решение владельца). Ненаказанная ошибка соперника всегда считается встреченной впервые, если позиция перед ней новая.

Если после выхода у игрока нет ходов в зоне и не было ошибок соперника — повторения нет.

### 3.4 Где это происходит

Запись идёт в том же хуке, что карточки позиций и задач, после разбора. Она изолирована: сбой записи пишется в журнал и не ломает ни разбор, ни карточки.

## 4. Процент

### 4.1 Процент карточки

Новая карточка — 0 %. Иначе min(1, ln(1 + S) / ln(22)), где S — стабильность FSRS в днях (общая спецификация, 4.3).

### 4.2 Процент позиции

Для узла n, цвета игрока C и уровня L — средний процент «элементов» под n, взвешенный вероятностью их встретить (общая спецификация, 4.4):
- **Узел соперника:** вероятности рёбер на уровне L как есть. Вес выхода из графа = вероятность дойти × (вероятность остатка + сумма вероятностей рёбер без продолжения + сумма вероятностей рёбер назад) — это вес карточки остатка узла для C.
- **Узел игрока:** карточка хода узла с весом «вероятность дойти». Дальше розыгрыш идёт по хорошим (идеальным и хорошим) рёбрам игрока, их вероятности нормированы между собой. Доля хороших рёбер без продолжения или назад уходит в карточку остатка узла для C; если хороших рёбер нет совсем, туда уходит весь вес.
- **Рёбра назад (решение владельца: правило «самая мелкая позиция цикла»).** Один раз при загрузке:
  1. глубина каждого узла — длина кратчайшего пути от пустого угла;
  2. компоненты сильной связности графа — это его циклы (двойное тенуки, ко);
  3. в каждой компоненте из нескольких узлов обход в глубину по её внутренним рёбрам начинается с самого мелкого узла (наименьшая глубина, при равенстве — меньший номер); его рёбра назад — рёбра, разрывающие цикл.

  Для двойного тенуки X → Y → X с X мельче режется второе тенуки Y → X: первое, главное продолжение позиции, остаётся в графе. Запись тренировки уходит из графа ровно на этих рёбрах (3.1), поэтому процент и запись совпадают. Оставшийся граф — без циклов, вероятности дойти считаются по нему в топологическом порядке (позиции, достигнутые разными порядками ходов, складываются).

Процент = Σ (вес × процент карточки) / Σ весов. Карточки, которых ещё нет, — 0 %.

### 4.3 Ветки, группы, сводка

- Процент ветки, группы и всего дерева = Σ (вес позиции × процент позиции) / Σ весов по их позициям списка.
- Вес позиции — вероятность дойти до её узла от пустого угла на уровне L для цвета C (по тем же правилам 4.2).
- Позиция, вложенная в другую, считается отдельно со своим весом.

### 4.4 «Пора повторить»

Позиция списка отмечается «пора повторить», если у её поддерева есть карточка хода или остатка с наступившим сроком FSRS. В сводке — число таких позиций.

### 4.5 Когда пересчитывается

Проценты считаются на сервере по запросу. Кэш сбрасывается при:
- новой записи после тренировки;
- смене уровня;
- смене цвета в запросе (кэш по цвету и уровню).

Расчёт по всему графу — доли секунды; для каждой позиции он не повторяется заново, а берётся из одного обхода.

## 5. Смена уровня

При сохранении нового уровня в настройках:
1. Для каждого повторения карточек графа автооценка выводится заново из сырых данных по порогам нового уровня. Ручная оценка, если есть, остаётся.
2. История каждой карточки проигрывается через FSRS с начала, получаются новые состояние и срок.
3. То же для нынешних карточек позиций и задач:
   - задача — из сохранённой потери ответа;
   - позиция — из сохранённого худшего хода. Если у повторения есть тренировка и её разбор ещё в базе, худший ход выводится заново по всем ходам; иначе сохранённая категория «ненаказанная ошибка» остаётся как есть.
4. Проценты пересчитываются с весами нового уровня.

Пересчёт идёт в одной транзакции. Пока он идёт, настройки показывают «пересчёт прогресса…». Сбой отменяет пересчёт и смену уровня, а не только одно из двух.

## 6. Показ

### 6.1 Сводка над деревом «Из списка»

- «Освоено N %» для выбранного цвета, крупно, и полоса процента.
- «Пора повторить: K позиций».
- Если выбран случайный цвет — два числа: «за чёрных N %, за белых M %», полоса — среднее.

### 6.2 Строки дерева

- У групп, веток и позиций — тонкая полоса и процент (для случайного цвета — среднее двух).
- У позиций с наступившим сроком — отметка «пора повторить».
- Нынешние отметки первой итерации («изучается», «изучена», «изучено N из M») при наличии весов заменяются процентами. Без весов они остаются.

### 6.3 Выбранная позиция

Рядом с полным названием — процент и, если пора, «пора повторить». Строка карточки позиции («когда повторять») остаётся, пока очередь работает с карточками позиций (часть 3 это изменит).

### 6.4 Тексты

Новые ключи во всех шести каталогах; термины по глоссарию. Например: «освоено {percent}», «пора повторить: {count}» (формы множественного числа), «за чёрных», «за белых», «пересчёт прогресса…».

## 7. API

- `GET /api/progress?color=B|W` → `{ hasWeights, level, overall: { percent, due }, positions: { [listId]: { percent, weight, due } } }`. Ветки и группы клиент считает сам по структуре списка, которая у него уже есть.
- Смена уровня (`PUT /api/player`) запускает пересчёт (раздел 5) и отвечает после него.

## 8. Проверка

- **Сервер:**
  - проход тренировки по графу: ход по ребру, выход по трём причинам, тенуки, другой угол и отражение;
  - стартовые ходы без повторений;
  - повторения карточек хода с оценками;
  - карточка остатка, включая правило «впервые»;
  - «переиграть с хода N» не засчитывается;
  - процент карточки;
  - процент позиции на маленьком графе с известным ответом, включая перестановку и цикл через тенуки;
  - ветки и сводка;
  - пересчёт при смене уровня, включая ручные оценки и старые карточки;
  - без весов.
- **Веб:** тесты чистой логики агрегации по дереву и форматирования.
- **Сквозной тест:** сервер с маленьким графом и весами (из фикстур). Тренировка по ветке, потом процент в строке и в сводке растёт; смена цвета; смена уровня меняет процент.

## 9. Решения владельца по вопросам

1. **«Переиграть с хода N» не засчитывается** в прогресс (3.3 и 2.3).
2. **Случайный цвет:** в строках — среднее двух цветов, в сводке — оба числа (6.1, 6.2).
3. **Отметки первой итерации при наличии весов заменяются процентами** (6.2).
4. **Пересчёт при смене уровня сдвигает и сроки** карточек позиций и задач в очереди — это ожидаемо (раздел 5).
