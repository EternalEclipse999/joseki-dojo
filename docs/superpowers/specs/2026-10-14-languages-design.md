# Joseki Dojo — языки интерфейса

- Дата: 2026-10-14
- Статус: согласовано в обсуждении
- Термины го на всех языках: [словарик](2026-10-14-languages-glossary.md)

## 1. Цель

Приложение говорит на шести языках: английском (по умолчанию), русском, китайском упрощённом, китайском традиционном, корейском и японском. Язык меняется на лету, без перезапуска; установщик Windows и первый запуск спрашивают язык.

## 2. Объём

**Входит:**
- весь текст интерфейса (`packages/web`), включая подписи, подсказки, `aria-label` и `title`;
- сообщения сервера, которые видит игрок: ошибки, состояние KataGo, установка KataGo, смена движка, сохранение настроек (раздел 6);
- текст desktop-оболочки: окно ошибки запуска, ошибки обновления;
- названия 88 позиций и 17 веток «Из списка» (раздел 7) и правка русских названий, неверно называющих ход (раздел 7.1);
- выбор языка в установщике Windows и на экране первого запуска (раздел 8).

- README (на английском, как сейчас): выбор языка при установке и на первом запуске, переключение в настройках и в шапке, шрифты для иероглифов на Linux, файл переводов названий `starts-i18n.json` и что при правке списка его тоже надо дополнить.

**Не входит:** журналы сервера и KataGo, ошибки чтения баз (видны только в журнале), инструменты разработчика (`npm run setup`, `traps:*`, `jdb:dump`), переводы README и документов. Они остаются как есть.

## 3. Языки и хранение

| Код | Название в списке | `lang` у `<html>` | Код языка Windows (LANGID) |
|---|---|---|---|
| `en` | English | `en` | 1033 |
| `ru` | Русский | `ru` | 1049 |
| `zh-Hans` | 简体中文 | `zh-Hans` | 2052 |
| `zh-Hant` | 繁體中文 | `zh-Hant` | 1028 |
| `ko` | 한국어 | `ko` | 1042 |
| `ja` | 日本語 | `ja` | 1041 |

- Порядок в списках — как в таблице. Каждый язык подписан на себе самом.
- Язык хранится в файле настроек рядом с темой: `ui.language`. `GET /api/ui` отдаёт его, `PUT /api/ui` с `{ language }` сохраняет (как тему). Неизвестный код — ошибка 400.
- Нет `ui.language` в файле — интерфейс английский, а приложение показывает экран выбора языка (раздел 8.2). `UiSettings.language` необязательное: его отсутствие и значит «язык ещё не выбран».
- Миграции нет: у тех, кто уже играл, после обновления интерфейс становится английским до выбора на экране языка.

## 4. Словари и форматирование

### 4.1 Словари
- `packages/shared/src/i18n/`: `ru.ts` — образец (ключ → текст), `en.ts`, `zh-Hans.ts`, `zh-Hant.ts`, `ko.ts`, `ja.ts`. Тип каждого словаря выводится из `ru.ts`: нет ключа — ошибка typecheck.
- Ключи — по экранам и местам: `start.title`, `review.next`, `error.session.notOnList`, `install.step.benchmarkingGpu`…
- Значение — строка или набор форм множественного числа `{ one?, two?, few?, many?, other }` (формы CLDR). Параметры в фигурных скобках: `{rank}`, `{count}`, `{detail}`.
- Тест сверяет словари: одинаковые ключи, одинаковые параметры в каждой строке, у множественных форм — все категории, которые `Intl.PluralRules` этого языка может выбрать.

### 4.2 Функция перевода
- `t(lang, key, params)` в `packages/shared`: подставляет параметры; для множественного значения выбирает форму по `params.count` через `Intl.PluralRules(lang)`; числа в параметрах форматирует `Intl.NumberFormat(lang)` (дробная часть — как сейчас, до 0,1 очка).
- Веб: язык в контексте Preact; `useT()` отдаёт `t` текущего языка, и все экраны перерисовываются при смене.
- Уровни бота: `rankLabel` берёт формат из словаря (`7 кю` / `7k` / `7级`…, словарик).

### 4.3 Термины
Термины го на всех языках зафиксированы в [словарике](2026-10-14-languages-glossary.md) с источниками. Строки словарей и названия позиций используют только их. Переводы делает Claude; термины сверены по источникам (Sensei's Library, википедии го на каждом языке, словари федераций). Перевод на китайский, корейский и японский стоит показать носителю, который играет в го (раздел 10).

## 5. Переключение языка

- **Настройки:** пункт «Язык» рядом с темой — шесть вариантов. Выбор сразу меняет язык и сохраняется (`PUT /api/ui`).
- **Шапка:** иконка глобуса справа, рядом с «Игра / Настройки», с подписью для экранных читалок «Язык». Щелчок открывает меню из шести языков, у текущего — галочка. Меню закрывается выбором, щелчком мимо и клавишей Esc; стрелки ходят по пунктам, Enter выбирает.
- **Мгновенно:** смена языка перерисовывает весь интерфейс, включая уже показанные сообщения сервера (они приходят ключами, раздел 6) и названия позиций (раздел 7). Текущая тренировка и разбор не прерываются.
- **Без мигания при запуске:** последний язык запоминается в браузере (`localStorage`) и применяется сразу; ответ `GET /api/ui` его уточняет.
- **`<html lang>`** — по таблице раздела 3: от него зависит начертание иероглифов (один и тот же знак в японском, китайском и корейском рисуется по-разному).
- **Шрифты:** Inter остаётся для латиницы и кириллицы; после него — системные шрифты языка: `zh-Hans` — Microsoft YaHei, PingFang SC, Noto Sans CJK SC; `zh-Hant` — Microsoft JhengHei, PingFang TC, Noto Sans CJK TC; `ja` — Yu Gothic UI, Hiragino Sans, Noto Sans CJK JP; `ko` — Malgun Gothic, Apple SD Gothic Neo, Noto Sans CJK KR. Выбор — по `:lang()`.
- **Desktop:** язык нужен оболочке только для окна ошибки запуска. Она берёт его сама: сначала из файла установщика `installer-language`, потом из `ui.language` в файле настроек (раздел 8.1); ничего нет — английский.

## 6. Сообщения сервера

- Новый тип в `packages/shared`: `LocalizedText = { key: MessageKey; params?: Record<string, string | number | LocalizedText> }`, где `MessageKey` — ключи словаря. Параметр может сам быть `LocalizedText` (вложенный текст): он переводится на тот же язык, что и внешний.
- Поля, которые сейчас несут готовый русский текст, становятся `LocalizedText`:
  - ошибка по WebSocket: `{ type: 'error'; code; text: LocalizedText }`;
  - `HealthResponse.reason`;
  - `InstallStatus.error`, `InstallStatus.note`, `InstallFile.label`;
  - причина отказа смены движка в настройках;
  - ошибка `PUT /api/ui`;
  - ошибка обновления в desktop: `AppUpdateState` со статусом `error`.
- Ошибки сервера, которые видит игрок (`SessionError`, `EngineError`, ошибки установки и загрузки, недопустимый ход), несут ключ и параметры вместо строки. Сообщение для журнала собирается из них на английском.
- Текст, который сочиняем не мы — вывод KataGo, системная ошибка (`ECONNRESET`, код выхода процесса), — идёт параметром `detail` как есть: «Не удалось скачать файл: {detail}».
- Неожиданная ошибка без ключа — `error.internal` с `detail`.
- Веб показывает `LocalizedText` через `t` текущего языка; при смене языка показанное сообщение переводится заново.

## 7. Названия позиций

- Русские названия остаются в `starts-list.json`; внешние скрипты сборки (раздел 3.5 спецификации стартовых позиций) не меняются.
- Переводы — в новом файле `packages/server/bases/starts-i18n.json`:
  ```json
  {
    "Q16 O17 R14": { "en": { "name": "Small approach — keima answer", "short": "Keima answer" }, "zh-Hans": { "name": "…", "short": "…" } },
    "Q16 O17": { "en": { "name": "Small approach" } }
  }
  ```
  Ключ — канонические ходы позиции или ветки, как в `starts-list.json`: ходы не меняются, а русское название может. У ветки только `name`. Пять языков на запись; русский берётся из списка.
- `StartListEntry.name` и `short`, `StartBranch.name` становятся наборами по языкам: `Record<Language, string>`. `GET /api/starts` отдаёт все языки, поэтому смена языка не требует нового запроса.
- Не хватает перевода — берётся английский, нет английского — русский; в журнал сервера — строка с ходами записи. Файла нет или он повреждён — все названия русские, строка в журнал.
- Группы (`4-4`, `3-4`…) одинаковы на всех языках; корень «Пустой угол» — из словаря.
- Крошки и заголовки берут название позиции по её идентификатору из списка на текущем языке; сохранённое в сессии название (`StartRef.name`, русское) — только для позиций, которых в списке больше нет.
- Тест: у каждой позиции и ветки отгружаемого списка есть `name` и (у позиций) `short` на всех пяти языках; лишних ключей нет.

## 8. Первый запуск и установщик

### 8.1 Установщик Windows
- `nsis.installerLanguages`: `en_US`, `ru_RU`, `zh_CN`, `zh_TW`, `ko_KR`, `ja_JP`; `displayLanguageSelector: true`. Окно выбора языка показывается до установки; установка дальше — как сейчас, в один щелчок, на выбранном языке.
- Английский выбран заранее при любом языке Windows: макрос `preInit` (выполняется до окна выбора) ставит `$LANGUAGE` в 1033.
- Макрос `customInstall` пишет выбранный `$LANGUAGE` (число) в файл `installer-language` в папке данных (`%APPDATA%\Joseki Dojo`) — только при обычной установке, не в тихом режиме.
- Автообновление запускает установщик в тихом режиме: окна выбора нет, файл не пишется, язык игрока не меняется. Окно в тихом режиме не показывает сам NSIS: в его макросе `MUI_LANGDLL_DISPLAY` вызов окна обёрнут проверкой `${Unless} ${Silent}` (NSIS 3.04 и новее); `preInit` только выбирает английский заранее. Проверяется установкой и обновлением на Windows до релиза (раздел 10).
- Desktop при запуске: есть файл `installer-language` — переводит LANGID в код (таблица раздела 3; неизвестный числовой LANGID — английский) и передаёт серверу параметром `initialLanguage`; сервер записывает его в `ui.language`, только если там пусто. После успешного старта сервера файл удаляется.
- Пустой или нечисловой файл `installer-language` (установщик остановился посреди записи) считается отсутствием выбора: показывается экран первого запуска (8.2). Если сервер не смог записать язык в настройки, он пишет об этом в журнал и всё равно стартует: экран выбора языка спросит игрока сам.
- Окно ошибки запуска берёт язык из файла `installer-language`, а если его нет — из `ui.language` в настройках: при первом запуске, который не удался, выбор установщика в настройки ещё не попал.

### 8.2 Экран выбора языка
- Показывается, когда в настройках нет `ui.language` (Linux, запуск из исходников, игроки прежних версий; после установщика Windows язык уже записан).
- Идёт первым, до установки KataGo и до экрана движка.
- Шесть кнопок, каждая подписана на своём языке, английская выделена; заголовок и подсказка — на английском. Щелчок сохраняет язык (`PUT /api/ui`) и продолжает обычный путь.

## 9. Проверка

**Юнит-тесты (без KataGo):**
- словари: одинаковые ключи и параметры, категории множественного числа по `Intl.PluralRules` (4.1);
- `t`: подстановка, множественное число в русском и английском, числа по языку, ключ без параметра;
- ошибки сервера уходят ключами с параметрами, текст чужих ошибок — в `detail` (6);
- `PUT /api/ui` с языком: сохранение, отказ на неизвестный код; `initialLanguage` записывается только в пустое `ui.language`;
- названия позиций: полнота `starts-i18n.json`, запасной язык, отсутствующий файл (7);
- LANGID → код языка, неизвестный → английский (8.1);
- когда показывается экран выбора языка (8.2).

**e2e** (`languages.spec.ts` идёт на своём сервере, порт 5183 с отдельным профилем в `e2e/.languages`: он сохраняет другие языки, и прерванный прогон не должен оставить в `e2e/config.e2e.json` чужой язык):
- глобус мгновенно меняет текст интерфейса и `<html lang>`, сервер сохраняет язык (`GET /api/ui`), после перезагрузки страницы язык тот же;
- настройки (радиокнопки языков) тоже переключают язык: `lang` и тексты японского словаря;
- названия позиций следуют языку: в режиме «Из списка» на английском дерево показывает английские название и подпись позиции из `starts-i18n.json` (фикстура `e2e/make-starts.ts`), а смена языка при открытом дереве переводит их на месте, оставляя ту же позицию;
- поздний ответ `GET /api/ui` не отменяет язык, выбранный до его прихода;
- экран первого запуска (`install.spec.ts`, профиль без `ui.language`): после выбора русского — экран установки на русском, после перезагрузки страницы язык тот же, а экран выбора не возвращается;
- уже показанная ошибка сервера переводится заново — это проверяет юнит-тест функции, которая её показывает: в e2e ошибку сервера надёжно не вызвать, ход вне зоны интерфейс не отправляет.

**Вручную (Windows):** окно выбора в установщике, английский выбран заранее; выбранный язык доходит до приложения; автообновление проходит без окна и не меняет язык.

## 10. Риски

- **Качество перевода.** Китайский, корейский и японский переводит Claude по словарику с источниками; носитель языка, играющий в го, должен посмотреть интерфейс и названия позиций. Неуверенные термины отмечены в словарике.
- **Окно выбора языка в тихом режиме установщика.** Если NSIS показал бы его и при `/S`, автообновление зависло бы. По исходникам NSIS окно в тихом режиме не показывается (8.1), но подтвердить это можно только установкой и обновлением на Windows до релиза.
- **Шрифты на Linux.** Без пакета Noto CJK иероглифы будут квадратиками; README говорит, какой пакет поставить (раздел 2).
