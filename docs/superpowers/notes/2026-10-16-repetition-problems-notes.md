# Повторение, вторая итерация (задачи): заметки к PR

- **Дата:** 2026-10-16.
- **Источники:** ветка `feat/repetition-problems`, [спецификация повторения](../specs/2026-10-15-repetition-design.md) (разделы 4.1–4.2, 5.4, 7), [план 2026-10-16-repetition-problems](../plans/2026-10-16-repetition-problems.md).
- **Что здесь:** решения, принятые по ходу работы без владельца, открытые вопросы и известные ограничения.

## 1. Что нужно сделать владельцу

Ничего нового. Пороги ошибок берутся из таблицы калибровки, если она есть (`npm run thresholds:gpu`, см. [заметки к первой итерации](2026-10-15-repetition-notes.md)). Пока её нет, действуют прежние 0,5 / 2 / 5.

## 2. Решения, принятые по ходу работы

1. **Откуда берутся задачи.** Задача появляется в двух случаях:
   - ваш ход в зоне угла оценён как ошибка или грубая ошибка; задачей становится позиция перед этим ходом;
   - соперник ошибся ходом в зоне угла, а вы не наказали; задачей становится позиция перед вашим ответом.

   Задачи появляются после разбора любой тренировки, не только со стартовой позиции. Ходы стартовой позиции не учитываются. Если одна позиция подходит под оба случая, задача одна, и помечена она как ненаказанная ошибка. Позиция, у которой в разборе нет вариантов KataGo, задачей не становится: без лучшего хода нечего показать.
2. **Одна позиция — одна задача.** Ключ задачи строится по позиции, перенесённой в правый верхний угол, с учётом зеркального отражения по диагонали. Та же позиция в другом углу или зеркальная — та же задача.
3. **Расписание.**
   - Новая задача сразу получает «Снова» и возвращается через минуту, на первом шаге обучения.
   - Если та же ошибка повторилась в новой тренировке, задача получает ещё одно «Снова», но не больше одного раза за тренировку.
   - Удалённая задача больше не появляется.
4. **Как KataGo оценивает ответ.**
   - Если ход есть среди вариантов из разбора тренировки, потеря берётся оттуда, и KataGo не нужен.
   - Иначе KataGo один раз анализирует позицию после хода, с числом визитов как у разбора. Этот запрос идёт вне очереди, как запрос при тэнуки, чтобы не ждать фоновый разбор.
   - Категория хода определяется по порогам текущего уровня игрока.
   - Автооценка: лучший ход KataGo — «Легко», точно — «Хорошо», неточность — «Трудно», ошибка и грубая ошибка — «Снова». Её можно поменять, как у позиций.
5. **Ответ можно дать в любой точке доски**, не только в зоне угла: лучшим ходом KataGo может оказаться и ход в другом месте.
6. **Экран задачи.**
   - Лучший ход KataGo показывается с веткой, по шагам, как в разборе. Слово «ветка», а не «вариант», выбрано по глоссарию: «вариант» — это ваш собственный вариант в разборе.
   - Панель называется «Повторение задачи» и показывает только автооценку: категория и потеря уже названы строкой выше.
   - Потеря, которая округляется до нуля, показывается без «−0,0», как в разборе.
7. **KataGo не готов.** На экране появляется «Оценка недоступна», ответ не засчитывается и ничего не записывается. «Дальше» снова покажет ту же задачу: она остаётся самой просроченной. Пока KataGo не работает, очередь всё равно не двигается, потому что для позиций нужен бот. Спецификация (5.4) уточнена.
8. **Кнопки очереди появляются и после ошибки запроса оценки.** Пример: задачу удалили в другом окне. Без этого из задачи можно было уйти только через шапку.
9. **Очередь при переходе в другой раздел.** Если открыта задача, переход в другой раздел завершает очередь: экран задачи живёт во вкладке «Повторение». Разбор позиции из очереди сохраняет «Дальше» и «Закончить», как в первой итерации.
10. **Повторение в разборе тренировки — только для позиций.** Панель в разборе относится к карточке позиции, даже если та же тренировка создала задачи. Задачи оцениваются только на своём экране.
11. **Сквозной тест задач.** В подставном KataGo появился штраф за один пункт (`FAKE_KATAGO_PENALTY`), чтобы тренировка содержала настоящую ошибку. Тест задач идёт на отдельном сервере (порт 5184) со своей папкой данных и копией настроек. Общую базу основного сквозного сервера он не трогает. Тест ждёт около минуты, пока задача станет «пора повторить» после первого шага обучения.

## 3. Открытые вопросы (некритичные)

1. **Разная база для потерь.** Потери вариантов из разбора считаются от лучшего варианта, а потеря хода вне списка — от оценки позиции до хода. При малом числе визитов ход вне списка может получить потерю чуть меньше, чем вариант из списка. Разбор тренировки устроен так же, поэтому правило оставлено общим.
2. **Слово «задача» в других языках.** В глоссарий добавлена строка «задача»: 問題 / 题目 / 題目 / 문제. Термины цумего не используются, потому что это не задача на жизнь и смерть. Строку стоит проверить вместе с переводами.
3. **Пороги задачи и пороги ответа.** Задача создаётся по порогам уровня на момент тренировки. Если потом поменять уровень, старые задачи не пересоздаются и не удаляются, а ответы оцениваются уже по новым порогам.

## 4. Известные ограничения

- **Нет тестов компонентов веба.** Автотестами не покрыты:
  - экран задачи;
  - панель задачи;
  - правило очереди при смене раздела;
  - защита от запоздалых ответов.

  Чистая логика отметок и текста вердикта вынесена в `problem-view.ts` и покрыта тестами. Весь путь (тренировка с ошибкой, фильтр, очередь, ответ, смена оценки, срок) проверяет сквозной тест.
- **Ветка на экране задачи — лучший ход KataGo из разбора тренировки.** Ход вне списка оценивается свежим анализом, но его собственная ветка не строится.
- **Задачи не попадают в отметки дерева «Из списка».** Отметки показывают только карточки позиций.
- **Связка уровня и визитов с оценкой ответа проверена только тестами сервиса.** Подставной KataGo в сквозных тестах не учитывает визиты, а без таблицы калибровки у всех уровней одинаковые пороги.
