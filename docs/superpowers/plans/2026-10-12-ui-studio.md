# Studio Look Implementation Plan

> **For agentic workers:** this is visual work. The controller executes it inline (superpowers:executing-plans) and checks every stage with screenshots in the browser pane. The design spec holds the exact values; this plan holds the structure, the order and the checks.

**Goal:** Restyle every screen of `packages/web` to the Studio look of `docs/superpowers/specs/2026-10-12-ui-studio-design.md` without changing behaviour, the server or the protocol.

**Architecture:** CSS custom properties for the tokens (light and dark), shared CSS classes (segmented control, chips, cards, fact rows, metrics) and two Preact components (header, bar), Shudan restyled through its CSS variables and classes, and a measured SVG overlay for the zone. Screens are rewritten one by one on top of these pieces.

**Tech Stack:** Preact 10, Vite 8, @sabaki/shudan, `@fontsource-variable/inter` (OFL), `lucide-preact` (ISC), Playwright.

## Global Constraints

- All colours, sizes and texts come from the spec; Russian UI text, English code and comments.
- Behaviour, API calls and message flow do not change. Native form controls stay (radios inside segmented controls and the corner picker, a range input for the rank) with the old labels: «Чёрные», «Белые», «Случайный цвет», «Левый верхний» … «Случайный угол».
- Headings and button names that e2e tests use stay: «Нужно скачать движок KataGo», «Обновление KataGo», «Подбор движка KataGo», «KataGo не настроен», «Настройки» (heading and header button), «Назад», «Установить», «Обновить», «Обновить движок», «Подобрать движок заново», «К разбору», «Закончить», «Показать ветку», «Переиграть с этого хода», «Сохранить и проверить». The start button becomes «Начать тренировку» (tests match «Начать» as a substring).
- The settings button is hidden during a game and during an engine update, as today.
- One accent-filled button per view.

## File structure

- `packages/web/src/styles/tokens.css` — colour tokens, light and dark (spec 3.1), font.
- `packages/web/src/styles/base.css` — reset, typography, buttons, segmented control, chips, cards, fact rows, metrics, bars, fields, progress, range input, header, layout grid.
- `packages/web/src/styles/board.css` — Shudan variables and overrides (board colours, labels, dimmed labels, selection, ghost ring, last-move point), zone overlay.
- `packages/web/src/styles/screens.css` — per-screen layout (start, game, review, settings, install, engine).
- `packages/web/src/styles.css` — removed; `main.tsx` imports the font and the four files.
- `packages/web/src/components/AppHeader.tsx` — brand, breadcrumb, «Игра / Настройки».
- `packages/web/src/components/Bar.tsx` — one bar for errors, the app update, the engine update and the version warning (`ErrorBanner`, `AppUpdateBanner` render through it).
- `packages/web/src/components/Board.tsx` — theme and zone overlay (replaces Shudan `lines`); new optional props `dimmed`, `selected`.
- `packages/web/src/zone-overlay.ts` (+ test) — pure geometry of the measured zone rectangle (the frame; the lighter wood outside the zone is a gradient on the goban background).
- `packages/web/src/review-summary.ts` (+ test) — the texts of the three summary tiles.
- `packages/web/src/rank-scale.ts` (+ test) — rank ↔ slider index, scale labels.
- Screens: `StartScreen.tsx`, `GameScreen.tsx`, `ReviewScreen.tsx`, `LossBar.tsx`, `SettingsScreen.tsx`, `InstallScreen.tsx`, `EngineScreen.tsx`, `App.tsx` (shell, header, bars, loading).
- `e2e/game.spec.ts` — new status and move-count texts.

## Stages (one commit each)

### Stage 1: Foundation, shell and board
- [ ] Add `@fontsource-variable/inter` and `lucide-preact` to `packages/web`.
- [ ] Tokens, base, board and screen CSS; remove `styles.css`.
- [ ] `AppHeader`, `Bar`; `App.tsx` renders header, bars and the loading state in the new style.
- [ ] Board: Shudan theme, zone overlay (dashed accent frame and light veil; measured from `.shudan-vertex[data-x][data-y]` rectangles, re-measured on resize), last move as an accent point.
- [ ] Unit tests for `zone-overlay.ts`; `npm test`, `npm run typecheck`; screenshots of the start and game screens (light and dark).

### Stage 2: Start and game screens
- [ ] Start screen per spec 5 (mode cards, corner picker on a mini board, colour segmented control, rank slider over `BOT_RANKS`, environment chips, «Начать тренировку»).
- [ ] Game screen per spec 6 (status, subtitle, fact rows, move chips, proposal card, hint, «Тэнуки» and «Закончить» with icons).
- [ ] Unit tests for `rank-scale.ts`; update `e2e/game.spec.ts`; screenshots at 1280×820 and 700×900.

### Stage 3: Review and the remaining screens
- [ ] Review per spec 7: metrics, full-width loss chart with the selected slot, navigator with ← → keys, move line with category badge, candidate rows, letters on the board (best — accent, others — dimmed), hover on a row selects its point, played move as a translucent stone with a category ring, branch stepper, «Территория» toggle, actions.
- [ ] Settings, install and engine screens per spec 8.
- [ ] `npm test`, `npm run typecheck`, `npm run e2e`; screenshots of every screen in both themes.
- [ ] Final whole-branch review (subagent), then mark the PR ready.
