# About Window Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An «О программе» window, opened by an `Info` button next to the language globe on every screen, shows the app version, the KataGo in use, the project links, the licence and the credits (spec `docs/superpowers/specs/2026-10-20-about-design.md`).

**Architecture:** The app version is the root `package.json` version, baked into the web build by Vite `define` (`__APP_VERSION__`; Vitest gets the same `define`). The engine block comes from a new `GET /api/about` served by `SettingsService.about()`. The web has `about.ts` (version, links, credits, the engine block's lines as pure functions) and `components/AboutDialog.tsx` (a native `<dialog>` opened with `showModal()`), mounted by `AppHeader`.

**Tech Stack:** TypeScript, Fastify, Preact, Vite, Vitest, Playwright.

## Global Constraints

- Work only in the worktree `D:\private\joseki-dojo-about` (branch `feat/about`); the main checkout `D:\private\joseki-dojo` is busy with other work and is never touched.
- The app version has one source: `version` in the root `package.json`. The server never reports it.
- `GET /api/about` → `AboutInfo` `{ katago: { lockedVersion, runningVersion: string | null, setup: 'cpu' | 'gpu' | 'manual' | 'missing', mainModel, humanModel } }`; the running version is asked only while health is `ready`, else (and on a failed question) `null`; `setup` is `missing` when `missingFiles(config) !== null`, else `config.setup?.kind ?? 'manual'`; network names are the file names without the folder and without `.bin.gz` / `.txt.gz` / `.bin`.
- The window: `<dialog>` + `showModal()`; Esc, the cross and a click on the backdrop close it; the focus goes back to the button; keys pressed inside it never reach the screen below (the review's ← → stay put); the screen below is never reset.
- The engine block is asked afresh on every opening; a late answer after closing is dropped; a failure shows «Сведения о движке недоступны» and no error bar.
- Links: `https://github.com/EternalEclipse999/joseki-dojo`, `…/releases`, `…/issues/new`; `<a target="_blank" rel="noreferrer">` (the desktop app already opens them in the external browser).
- Credits: KataGo, KataGo networks (katagotraining.org), the human-like network humanv0, Shudan, go-board, FSRS (ts-fsrs), Preact, Inter, Lucide, Electron — names and links only. **Never name the sources of the start positions or the traps**, anywhere.
- No «новое» mark on the button; no data folder, no «copy details», no update check in the window.
- User-facing text in all six catalogs (`packages/shared/src/i18n/{ru,en,ja,ko,zh-Hans,zh-Hant}.ts`); terms follow the glossary `docs/superpowers/specs/2026-10-14-languages-glossary.md` (network: ネットワーク / 网络 / 網路 / 네트워크; tested version and running: as in `settings.versions`).
- Code, comments, commits in English; one feature commit at the end (`feat(about): …`), trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; the spec and this plan stay in their own `docs:` commit. Commit email: the repository's noreply address.

  }
}

  async about(): Promise<AboutInfo> {
    const { config, lock } = this.d
    return {
      katago: {
        lockedVersion: lock.katago.version,
        runningVersion: await this.runningVersion(),
        setup: missingFiles(config) !== null ? 'missing' : (config.setup?.kind ?? 'manual'),
        mainModel: modelName(config.katago.mainModel),
        humanModel: modelName(config.katago.humanModel),
      },
    }
  }

  /** The running KataGo's version, asked only while it is ready; null otherwise or when the question fails. */
  private runningVersion(): Promise<string | null> {
    return this.d.health.get().state === 'ready' ? this.d.engine.version().catch(() => null) : Promise.resolve(null)
  }

```ts
import type { AboutInfo, MessageKey, Translate } from '@joseki-dojo/shared'

/** Spec (about) 3.1: the root package.json version, set at build time. */
export const APP_VERSION: string = __APP_VERSION__

const REPO = 'https://github.com/EternalEclipse999/joseki-dojo'

/** Spec (about) 2.3: the project's pages. */
export const PROJECT_LINKS: readonly { key: MessageKey; href: string }[] = [
  { key: 'about.links.project', href: REPO },
  { key: 'about.links.releases', href: `${REPO}/releases` },
  { key: 'about.links.issues', href: `${REPO}/issues/new` },
]

/** Spec (about) 2.3: what the app is built on. A project's name is never translated; what describes a network is. */
export type Credit = { href: string } & ({ name: string } | { key: MessageKey })

export const CREDITS: readonly Credit[] = [
  { name: 'KataGo', href: 'https://github.com/lightvector/KataGo' },
  { key: 'about.credits.networks', href: 'https://katagotraining.org' },
  { key: 'about.credits.human', href: 'https://github.com/lightvector/KataGo/releases/tag/v1.15.0' },
  { name: 'Shudan', href: 'https://github.com/SabakiHQ/Shudan' },
  { name: 'go-board', href: 'https://github.com/SabakiHQ/go-board' },
  { name: 'FSRS (ts-fsrs)', href: 'https://github.com/open-spaced-repetition/ts-fsrs' },
  { name: 'Preact', href: 'https://preactjs.com' },
  { name: 'Inter', href: 'https://rsms.me/inter/' },
  { name: 'Lucide', href: 'https://lucide.dev' },
  { name: 'Electron', href: 'https://www.electronjs.org' },
]

export const creditText = (c: Credit, t: Translate): string => ('name' in c ? c.name : t(c.key))

const SETUP: Record<AboutInfo['katago']['setup'], MessageKey> = {
  cpu: 'about.engine.cpu',
  gpu: 'about.engine.gpu',
  manual: 'about.engine.manual',
  missing: 'about.engine.missing',
}

/** Spec (about) 2.3: the engine block's lines; no networks while KataGo is missing. */
export function engineLines(k: AboutInfo['katago'], t: Translate): { versions: string; setup: string; networks: string[] } {
  return {
    versions:
      k.runningVersion === null
        ? t('about.engine.versionsNotRunning', { locked: k.lockedVersion })
        : t('about.engine.versions', { locked: k.lockedVersion, running: k.runningVersion }),
    setup: t(SETUP[k.setup]),
    networks: k.setup === 'missing' ? [] : [k.mainModel, k.humanModel],
  }
}
```

Create `packages/web/src/components/AboutDialog.tsx`:

```tsx
import type { AboutInfo } from '@joseki-dojo/shared'
import { LoaderCircle, X } from 'lucide-preact'
import { Fragment } from 'preact'
import { useEffect, useRef, useState } from 'preact/hooks'
import { APP_VERSION, CREDITS, creditText, engineLines, PROJECT_LINKS } from '../about'
import { fetchAbout } from '../api'
import { useT } from '../i18n'
import { Logo } from './Logo'

type Engine = { kind: 'loading' } | { kind: 'ready'; info: AboutInfo } | { kind: 'failed' }

/**
 * Spec (about) 2.2: the «О программе» window over the current screen, open while it is mounted. Esc, the cross and a
 * click on the backdrop (it lands on the dialog itself: the dialog has no padding, its content fills it) all close the
 * dialog first and report through its `close` event: while it is still modal the page behind is inert, and the header
 * could not take the focus back. Keys pressed in it stop here, so that the screen below (the review's ← →) does not react.
 */
export function AboutDialog({ onClose }: { onClose: () => void }) {
  const t = useT()
  const ref = useRef<HTMLDialogElement>(null)
  const [engine, setEngine] = useState<Engine>({ kind: 'loading' })
  const close = (): void => ref.current?.close()

  // Removing an open modal dialog from the page takes it out of the top layer: no cleanup needed.
  useEffect(() => {
    ref.current?.showModal()
  }, [])

  // Spec (about) 3.3: asked on every opening; an answer after the window closed is dropped.
  useEffect(() => {
    let cancelled = false
    fetchAbout()
      .then((info) => !cancelled && setEngine({ kind: 'ready', info }))
      .catch((err: unknown) => {
        console.warn('about', err)
        if (!cancelled) setEngine({ kind: 'failed' })
      })
    return () => {
      cancelled = true
    }
  }, [])

  return (
    <dialog
      ref={ref}
      class="about"
      aria-label={t('about.title')}
      onClose={onClose}
      onClick={(e) => e.target === e.currentTarget && close()}
      onKeyDown={(e) => e.stopPropagation()}
    >
      <div class="about-body">
        <div class="about-head">
          <Logo />
          <div>
            <h2>Joseki Dojo</h2>
            <p>{t('about.version', { version: APP_VERSION })}</p>
          </div>
          <button class="icon ghost about-close" aria-label={t('about.close')} title={t('about.close')} onClick={close}>
            <X aria-hidden="true" />
          </button>
        </div>
        <p>{t('about.description')}</p>

        <section>
          <h3>{t('about.engine.title')}</h3>
          {engine.kind === 'loading' && (
            <p class="status-line muted">
              <LoaderCircle class="spin" aria-hidden="true" />
              {t('app.loading')}
            </p>
          )}
          {engine.kind === 'failed' && <p class="muted">{t('about.engine.failed')}</p>}
          {engine.kind === 'ready' && <EngineBlock info={engine.info} />}
        </section>

        <section>
          <h3>{t('about.links.title')}</h3>
          <ul>
            {PROJECT_LINKS.map((l) => (
              <li key={l.href}>
                <a href={l.href} target="_blank" rel="noreferrer">
                  {t(l.key)}
                </a>
              </li>
            ))}
          </ul>
        </section>

        <section>
          <h3>{t('about.license.title')}</h3>
          <p>{t('about.license.text')}</p>
          <p class="muted">{t('about.credits.title')}</p>
          <ul>
            {CREDITS.map((c) => (
              <li key={c.href}>
                <a href={c.href} target="_blank" rel="noreferrer">
                  {creditText(c, t)}
                </a>
              </li>
            ))}
          </ul>
        </section>
      </div>
    </dialog>
  )
}

function EngineBlock({ info }: { info: AboutInfo }) {
  const t = useT()
  const lines = engineLines(info.katago, t)
  return (
    <>
      <p>{lines.versions}</p>
      <p>{lines.setup}</p>
      {lines.networks.length > 0 && (
        <p>
          {t('about.engine.networks')}{' '}
          {lines.networks.map((n, i) => (
            <Fragment key={n}>
              {i > 0 && t('common.listSeparator')}
              <code>{n}</code>
            </Fragment>
          ))}
        </p>
      )}
    </>
  )
}
```
